# Data for in-browser {webr-r} cells — CC0 1.0 Universal

The CSV files in this directory are dedicated to the public domain under
[CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/). They are small
sampled slices (< 40 KB each) of the teaching datasets used in this book,
generated by `scripts/make-webr-samples.R` (seed 42):

- `ecom_sample.csv` — 400 rows: device, referrer, purchase, site-behavior and order columns
- `mockstrings_sample.csv` — 40 rows: id, email, imageurl, url (columns used in the strings chapter)
- `transact_sample.csv` — 300 rows: Invoice, Due, Payment dates

Full datasets remain static examples + downloadable exercise files only (see
the WebR manifest in `roadmap/webr-manifest.md`) and are never preloaded into
the browser.
